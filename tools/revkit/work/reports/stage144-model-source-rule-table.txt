- `FUN_1002e990` walks 24-byte records. The observed record layout is six
  little-endian dwords: key pointer, key length, auxiliary pointer, flag,
  handler pointer, and additional pointer. Entry 31 has key length zero and

Ported behavior

- `text.Paul2013ModelSourceRuleDescriptors` returns a copy of the 31-entry
  key/order/metadata inventory. It preserves observed addresses without
  asserting meanings for opaque table pointers.
- `text.BindPaul2013ModelSourceRules` combines that inventory with explicit
  handler implementations keyed by observed handler address. It refuses to
  bind an absent handler. `text.DispatchPaul2013ModelSourceRule` then performs
  the generic longest-key selection and selected-handler cursor behavior
  described in Stage 143.
- Tests check all 31 keys in order, copy isolation, metadata binding, and
  fail-closed behavior when handlers are absent.

Limits

- This is a static table transcription, not runtime table parity. Handler
  semantics remain unported except where separate Go APIs explicitly cover a
  narrow behavior such as the exact self-closing `<vtml_pause time="N"/>`
  lexical boundary. That API has not been connected to this table dispatcher.
- Decompiled handler bodies are incomplete or depend on parser/model state.
  The inventory does not imply support for arbitrary VTML, SSML, attribute
  ordering, nested tags, settings, phoneme tags, or audio effects.
- No original-DLL differential was captured for these 31 entries.
