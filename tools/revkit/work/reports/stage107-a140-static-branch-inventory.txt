Boundary

This inventory establishes coverage for the direct suffix comparisons visible
in the named pseudocode. It does not establish that every branch in
FUN_1000a140 has been translated: table-driven and state-dependent paths still
need branch-by-branch comparison, and the exact upstream exception rows,
resource/state production, and runtime output parity are not established. The
Go engine remains an independent, evidence-bounded implementation.
