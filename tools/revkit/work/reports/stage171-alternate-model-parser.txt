  The scanner return advances the source pointer and absolute offset.

  '>'; bracket contents are skipped until single-byte ']'. Closing tests
  use text byte/length, without an extra status gate.
- A failed/full append returns low-short 0; invalid branches return -1.
  The high return bits on those paths are not characterized by this port.
